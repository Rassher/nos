# NOS

Un escritorio minimalista para Windows 11, hecho en Rust: barra superior, dock y buscador, al estilo de un Mac.
Ligero (unos 15 MB de memoria) y sin navegador por dentro.

## Qué trae

- **Barra superior** con la app activa, reloj, programas, carpetas, volumen, red, bandeja y notificaciones.
- **Dock** con miniaturas de las ventanas, autoocultar y apps fijadas que se reordenan arrastrando.
- **Buscador** con Alt+Espacio, para apps y carpetas.
- **Vista rápida**: pulsa Espacio en el Explorador para ver un archivo sin abrirlo (imágenes, código, vídeo, música, comprimidos).
- **Widgets del escritorio**: reloj, tiempo, música, Steam, rendimiento y calendario.
- **Modo juego**: con un juego a pantalla completa, la barra y el dock se apartan.
- **Optimizador de Windows**: privacidad, publicidad y rendimiento. Todo se puede deshacer.
- **Modo shell (en pruebas)**: NOS puede sustituir a la barra de Windows del todo. Trae Alt+Tab propio, atajos Win+tecla y teclas de volumen.

## Seguridad

- No inyecta nada en otros procesos, así que es compatible con los anticheats.
- No toca archivos de Windows.
- Para volver a la barra de Windows: menú NOS → "Volver a la barra de Windows…".
